# kintone連携 展示会・セミナーHTML生成 簡易設計書

## 1. 目的

展示会・セミナー情報をkintoneで管理し、登録内容からWordPress / SWELLに貼り付けるHTMLを自動生成する。

現在のHTMLでは、開催予定、終了分、上部CTA、下部CTAなどに同じイベント情報が複数箇所へ記載されているため、kintoneを情報元として一元管理する。

---

## 2. システム概要

```text
kintone
  ↓
イベント情報を登録
  ↓
JavaScriptでデータ取得
  ↓
開催予定 / 終了済を自動判定
  ↓
HTML生成
  ↓
プレビュー・コピー
  ↓
WordPress / SWELLへ貼り付け
```

初期版ではWordPressへの自動更新は行わず、HTML生成・コピーまでを対象とする。

---

## 3. kintoneアプリ

アプリ名：

**展示会・セミナー管理**

1イベントにつき1レコードとする。

### 主なフィールド

| 項目     | フィールドコード          | 種類      |
| ------ | ----------------- | ------- |
| イベント名  | event_name        | 文字列     |
| 開催日    | event_date        | 日付      |
| 都道府県   | prefecture        | ドロップダウン |
| 会場     | venue             | 文字列     |
| イベント種別 | event_type        | ドロップダウン |
| 公開状態   | publish_status    | ドロップダウン |
| 申込みURL | apply_url         | リンク     |
| 詳細URL  | detail_url        | リンク     |
| チラシURL | flyer_url         | リンク     |
| 来場社数   | visitor_companies | 数値      |
| 来場人数   | visitors          | 数値      |

公開状態は以下とする。

```text
下書き
公開
非公開
```

HTML生成対象は「公開」のレコードのみとする。

## 6. 開催予定・終了済の判定

開催状態は入力させず、開催日からJavaScriptで自動判定する。

```text
開催日 >= 今日
→ 開催予定

開催日 < 今日
→ 終了分
```

開催予定は開催日の昇順、終了分は開催日の降順で表示する。

## 7. HTML生成対象

現在のHTMLから、主に以下を自動生成する。

### 開催予定

* 開催日
* 都道府県
* 会場
* イベント種別
* セミナー内容
* 出展内容
* 申込みURL
* 詳細URL
* チラシURL

現在の開催予定カードもこの情報で構成されている。

### 終了分

* 開催日
* 都道府県
* 会場
* 来場社数
* 来場人数
* セミナー内容
* 出展内容
* 詳細URL
* チラシURL

### CTA

開催予定のうち、申込みURLが設定されている直近イベントを表示する。

現在のHTMLでは上部と下部の両方に申込みCTAが存在するため、同じkintoneデータから生成する。

---

## 9. JavaScript概要

主要処理は以下とする。

```text
① kintone一覧画面に
   「HTML生成」ボタンを表示

② 公開レコードを取得

③ kintoneデータをJS用データへ変換

④ 今日の日付から
   開催予定 / 終了済を分類

⑤ HTML生成

⑥ プレビュー表示

⑦ HTMLをクリップボードへコピー
```

---

## 10. JavaScript関数構成

```js
getEvents()
```

kintoneから公開イベントを取得する。

```js
normalizeRecord()
```

kintoneレコードをHTML生成しやすい形式へ変換する。

```js
classifyEvents()
```

開催予定と終了済に分類する。

```js
renderUpcomingCard()
```

開催予定カードを生成する。

```js
renderPastEvent()
```

終了イベントを生成する。

```js
renderHero()
```

ページ上部のCTAを生成する。

```js
renderSticky()
```

ページ下部の固定CTAを生成する。

```js
generateHtml()
```

ページ全体のHTMLを生成する。

```js
showPreview()
```

生成結果をプレビューする。

```js
copyHtml()
```

HTMLをコピーする。

## 12. 運用方法

### 新しいイベントを追加する場合

```text
kintoneで新規レコード作成
↓
開催日・会場等を入力
↓
セミナー・出展情報を入力
↓
URLを入力
↓
公開状態を「公開」
↓
HTML生成
↓
WordPressへ貼り付け
```

### イベント終了後

HTMLを手作業で「開催予定」から「終了分」へ移動する必要はない。

開催日の翌日以降にHTMLを再生成すると、自動的に終了分へ移動する。

必要に応じて来場社数・来場人数だけkintoneへ追加入力する。

---

## 13. 初期版の対象範囲

実装するもの：

* kintoneイベント管理
* 開催予定・終了分の自動判定
* HTML自動生成
* CTA自動生成
* プレビュー
* HTMLコピー

実装しないもの：

* WordPressへの直接更新
* WordPress認証情報の管理
* 自動公開
* 画像アップロード

---

## 14. 完成イメージ

最終的な運用は以下とする。

```text
イベント情報の変更
       ↓
kintoneだけ修正
       ↓
HTML生成ボタン
       ↓
プレビュー確認
       ↓
HTMLコピー
       ↓
WordPress更新
```

これにより、開催予定カード、終了分、イベント件数、上部CTA、下部CTAを個別に修正する作業を不要にする。
