LOGI-Cube 資料ダウンロードページ 設置手順

この手順書は、WordPressの固定ページに「LOGI-Cube プロフィールブック」資料ダウンロードページを設置するためのものです。
テーマファイル、PHPファイル、functions.phpは編集しません。


1. WordPressで固定ページを新規作成する方法

1. WordPress管理画面にログインします。
2. 左メニューの「固定ページ」を開きます。
3. 「新規追加」をクリックします。
4. タイトルに「LOGI-Cube 資料ダウンロード」など、管理しやすい名前を入力します。
5. 本文エリアは、次の手順でカスタムHTMLブロックを追加して作成します。


2. SWELLでサイドバーなしにする方法

1. 固定ページの編集画面を開きます。
2. 右側の設定パネルで「固定ページ」タブを開きます。
3. 「SWELL設定」または「表示の上書き設定」の中にあるサイドバー設定を探します。
4. 「サイドバーを表示しない」「サイドバーなし」「1カラム」などを選択します。
5. 設定名はSWELLのバージョンや管理画面の状態で少し変わる場合があります。見つからない場合は、編集画面内で「サイドバー」という文字を探してください。


3. カスタムHTMLブロックの追加方法

1. 本文エリアで「＋」ボタンをクリックします。
2. 検索欄に「カスタムHTML」と入力します。
3. 「カスタムHTML」ブロックを選択します。
4. 追加された入力欄に、HTMLを貼り付けます。


4. HTMLを貼り付ける位置

1. output/logi-cube-download.html を開きます。
2. ファイルの中身をすべてコピーします。
3. 固定ページ本文の「カスタムHTML」ブロックに貼り付けます。
4. HTMLの一番上にある次の仮文字列は、あとで画像URLに差し替えます。

LOGI_CUBE_LOGO_URL
PROFILE_BOOK_COVER_URL


5. 追加CSSを貼り付ける場所

1. WordPress管理画面の左メニューから「外観」を開きます。
2. 「カスタマイズ」をクリックします。
3. 「追加CSS」を開きます。
4. output/logi-cube-download.css の中身をすべてコピーします。
5. 追加CSS欄の末尾に貼り付けます。
6. 「公開」を押す前に、プレビューで崩れがないか確認します。


6. 画像URLの取得方法

1. WordPress管理画面の左メニューから「メディア」を開きます。
2. 「新しいメディアファイルを追加」をクリックします。
3. 次の画像をアップロードします。

ロゴ画像:
materials/logi-cube-logo.png/commoncomcube.png

資料表紙画像:
output/profile-book-cover.webp

4. アップロードした画像をクリックします。
5. 右側または詳細画面に表示される「ファイルのURL」をコピーします。


7. 仮画像URLを差し替える方法

1. 固定ページのカスタムHTMLブロックを開きます。
2. HTML内の LOGI_CUBE_LOGO_URL を、WordPressで取得したロゴ画像URLに差し替えます。
3. HTML内の PROFILE_BOOK_COVER_URL を、WordPressで取得した資料表紙画像URLに差し替えます。
4. URLの前後にあるダブルクォーテーションは消さないでください。

例:
src="LOGI_CUBE_LOGO_URL"

これを次のようにします。

src="https://example.com/wp-content/uploads/2026/08/commoncomcube.png"


8. フォームを別ブロックで設置する方法

このHTMLでは、実際のformタグや送信処理は作っていません。
フォームプラグインやSWELLのフォームブロックを後から置けるように、フォーム設置エリアだけ用意しています。

1. 固定ページの本文で、資料請求フォーム設置エリアまで移動します。
2. HTML内には次のコメントがあります。

<!-- 資料請求フォーム設置開始 -->
<!-- 資料請求フォーム設置終了 -->

3. カスタムHTMLブロック内でショートコードが動かない場合は、フォーム部分だけを別ブロックで設置してください。
4. その場合は、カスタムHTMLブロックの直後、またはフォーム設置エリアの近くに「ショートコード」ブロックやフォームプラグインの専用ブロックを追加します。
5. 不要になったプレースホルダー文「ここに資料請求フォームを設置します。」は削除して構いません。
6. フォームには次の項目を入れてください。

会社名
お名前
メールアドレス
電話番号
個人情報保護方針への同意


9. プレビュー方法

1. 固定ページ編集画面の右上にある「プレビュー」をクリックします。
2. 「新しいタブでプレビュー」を開きます。
3. ページ上部から下部まで確認します。
4. 「無料で資料をダウンロード」ボタンを押し、フォーム設置エリアへ移動するか確認します。
5. FAQをクリックし、開閉できるか確認します。FAQはJavaScriptではなくHTML標準のdetails要素で動きます。


10. スマートフォン表示の確認方法

1. プレビュー画面を開きます。
2. ブラウザの幅を狭くします。
3. 可能であれば、スマートフォン実機でも確認します。
4. 次の点を確認します。

横スクロールが出ていない
文字がはみ出していない
ボタンが押しやすい大きさになっている
画像が画面幅からはみ出していない
カードが1列で表示されている


11. 公開前の確認項目

公開前に、次の項目を確認してください。

LOGI_CUBE_LOGO_URL が本物の画像URLに差し替わっている
PROFILE_BOOK_COVER_URL が本物の画像URLに差し替わっている
資料請求フォームが設置されている
フォーム送信後の案内が正しく設定されている
個人情報保護方針への同意項目がある
ボタンを押すとフォーム設置エリアへ移動する
FAQが開閉できる
PC、タブレット、スマートフォンで表示が崩れていない
サイドバーなしの表示になっている
不要なテスト文や仮URLが残っていない


12. 元に戻す方法

ページを公開前に戻したい場合:

1. 固定ページの編集画面を開きます。
2. 追加したカスタムHTMLブロックを削除します。
3. 追加したフォームブロックも削除します。
4. 更新ボタンを押します。

追加CSSを元に戻したい場合:

1. WordPress管理画面で「外観」から「カスタマイズ」を開きます。
2. 「追加CSS」を開きます。
3. output/logi-cube-download.css から貼り付けたCSS部分を削除します。
4. 「公開」をクリックします。

ページ自体を使わない場合:

1. 固定ページ一覧を開きます。
2. 該当ページを「下書き」に戻すか、「ゴミ箱へ移動」します。


作成ファイル

output/logi-cube-download.html
WordPressのカスタムHTMLブロックに貼り付けるHTMLです。

output/logi-cube-download.css
WordPressの追加CSSに貼り付けるCSSです。

output/setup-guide.txt
この設置手順書です。

output/profile-book-cover.webp
PDFの1ページ目から作成した、プロフィールブックの表紙画像です。WordPressのメディアにアップロードして使用してください。
